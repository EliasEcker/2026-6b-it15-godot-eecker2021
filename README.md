# IT-15: Godot Engine 4 – Beginner Tutorials (Dodge the Creeps & Squash the Creeps 3D)

Startvorlage für Modul **IT-15** (BRG Kepler Graz, 6. Klasse). Dieses Repository ist die Basis für **alle** Aufgaben 15.1–15.9 – es wird **ein einziges** Schüler-Repository pro Person verwendet.

## Setup

1. Über **Use this template → Create a new repository** ein eigenes Repository erstellen.
2. **Repo-Name:** `<jahr>-<klasse>-it15-godot-<schueler-email-prefix>` (z. B. `2026-6b-it15-godot-mmuster2023`), **Sichtbarkeit: Public**.
3. Lokal klonen und in [Godot 4](https://godotengine.org/download) (Version 4.3+) über **Import** öffnen (`project.godot` auswählen).

## Ordnerstruktur

| Ordner | Inhalt | Aufgaben |
| :--- | :--- | :--- |
| `task-01-basics/` | Erste Szene, Nodes, GDScript-Experimente | 15.1–15.3 |
| `dodge_the_creeps/` | Vollständiges 2D-Spiel | 15.4–15.5 |
| `squash_the_creeps_3d/` | 3D-Spiel | 15.6 |
| `build_web/` | Web-Export (GitHub Pages / Teams) | 15.7–15.9 |
